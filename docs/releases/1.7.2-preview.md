# Axiom 1.7.2 Preview — visible update progress

Tools → Check for Updates immediately opens a progress window saying **Checking for updates…**, with an animated progress bar. When an update is found, it shows **Downloading Axiom …** with a percentage, followed by verification. The window closes before the final result/restart prompt. Cancel stops the operation; closing the progress window also cancels it.

Background checks stay quiet. Clicking Check for Updates during a background check opens that operation's progress window instead of starting another check.

Ben confirmed the 1.7.0 → 1.7.1 Bluebird update worked. This Preview addresses the silent wait he noticed. The check that downloads 1.7.2 still runs in the older UI; the new indicator is available after installing 1.7.2. Verify it by checking again afterward, even when no newer release exists.

No automatic installation or save behavior changes. Source remains private; CP/models and separate review scopes are unchanged. Packages remain unsigned and downloads are full packages.
