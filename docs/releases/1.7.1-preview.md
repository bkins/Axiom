# Axiom 1.7.1 Preview — Bluebird update test

A deliberately tiny visible change for testing the updater from 1.7.0:

- The window title now includes **Bluebird update test**.
- Tools → About Axiom shows **Update test: Bluebird** and version **1.7.1**.

In your installed 1.7.0 Preview, choose **Tools → Check for Updates**, then **Restart to update**. The normal save/discard/cancel prompts still apply. After restart, look for Bluebird in the title and confirm 1.7.1 in About.

This is a Preview test release. The functional change is tiny, but the updater currently downloads a full package (about 86 MB), not a small delta. Source remains private; CP/model components and user documents are unchanged. Packages are currently unsigned.
