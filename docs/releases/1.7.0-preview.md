# Axiom 1.7.0 Preview

This Windows x64 preview introduces update-enabled installation. Download and run **AxiomDesktop-win-x64-preview-Setup.exe** once. Later builds can be downloaded from within Axiom.

- Choose Stable or Preview in Tools → Update Settings; Preview receives test builds.
- Background checks run after startup and every six hours when enabled. Manual checks and download cancellation are available in Tools.
- A persistent Update ready button lets you restart when convenient. Unsaved tabs use normal save/discard/cancel prompts; a state backup precedes installation.
- Downloads do not install automatically on exit or startup. Switching to Stable waits for a newer release and never downgrades state.
- Existing Markdown, settings and recovery live separately from installed binaries. CP/backend/model packages and retained review builds are not updated.
- Offline editing and existing portable/manual installation remain available.

The source repository remains private; this repository distributes binaries only. This is a preview for testing, not Stable acceptance. Packages are currently unsigned. Windows may show a publisher warning, and managed work computers may require local IT approval.

The first release has no newer update to download. Full update delivery becomes visible when a subsequent Preview release is published. The local automated fixture exercises a real download, replacement and restart between distinct package versions.
